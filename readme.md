# QuirkyLabs

QuirkyLabs is a personal learning project built to experiment with frontend development concepts and software-style problem solving using JavaScript, HTML, and CSS.

## Purpose

This project exists as a sandbox for learning, testing ideas, and improving my understanding of how interactive web applications are structured and built. It is intended to demonstrate my growth as a developer and serve as a portfolio project.

## Current Features

- Interactive UI elements built with vanilla JavaScript
- Modular HTML/CSS structure
- Basic application logic and state handling
- Experimentation with layout and styling

## Learning Goals

Through this project, I am focusing on:
- Writing clean, readable JavaScript
- Organizing code in a maintainable way
- Understanding how UI and application logic interact
- Using Git and GitHub effectively for version control

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
